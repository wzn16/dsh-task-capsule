# 任务胶囊 · dsh-task-capsule

给 DeepSeek Harness 补一份**会话任务账本**：每个会话跑过什么、跑了多久、正常结束还是失败/被中断；你离开窗口时只提醒一次。

## 它做什么

- **任务胶囊**：会话 header 右侧一颗胶囊，显示进行中的任务数与耗时，圆点颜色分态（运行 / 等你确认 / 失败）。点开是任务下拉，点条目直接跳到对应会话。
- **一次打扰**：页面不在前台时，任务结束、工具等你批准、选项等你拍板，才弹卡 + 提示音；可选系统通知。
- **账本**：按天汇总、逐条详情、导出 CSV / JSONL。落在 `~/.dsh/dsh-task-capsule/ledger.jsonl`，1000 条 / 2MB 封顶后轮转。
- **等批准也算时间**：`approvalWaitMs` 记录今天有多少时间花在等工具批准上——原生不给这个数。
- **只读接口**：两个本机回环 + 同源校验的只读路由，供其它插件区间查询与导出。

## 怎么用

1. 安装后设置页多出「任务胶囊」分区，三组开关：提醒强度（安静 / 标准 / 看护）、提醒什么、怎么提醒。
2. 会话 header 右侧出现胶囊即为生效；失败时应用日志会写明缺哪个服务。
3. 想回看：设置页里的账本卡片，或直接读 `ledger.jsonl`。

## 安装

克隆仓库后，在 **插件 → 添加插件** 里选这个目录即可（面板自己登记 bundle，不用改 profile）。CLI 等价写法与手补 `dsh.profile.bundles` 的兜底步骤见仓库 README。

## 已知限制

- 只在 DSH 页面打开时有效——插件跑在渲染进程里，不是后台守护进程。
- 页面隐藏时浏览器会节流定时器，提醒最长延迟到分钟级；记录不丢。
- 多窗口各读各的账本视图，提示音与系统通知由本地租约选出一个窗口发出。
- 只接受本机回环访问：用局域网 IP、手机或 tailscale 打开 Web GUI 时，胶囊与通知失效。
- 账本保留 1000 条 / 2MB，更早的在面板里翻或直接导文件。

兼容性、字段字典与回滚办法在仓库的 `docs/` 下。
